# Prompt maestro utilizado como especificación funcional

Desarrollar una aplicación web completa llamada **Sistema IoT para monitoreo de temperatura y humedad en bodega de medicamentos**, con Laravel 13, PHP 8.3+, MySQL, Blade y API REST JSON.

El sistema debe incluir autenticación, usuarios, roles, bodegas, áreas, dispositivos IoT, credenciales por dispositivo, API para ESP8266/Wemos D1 Mini, lecturas de temperatura, humedad, batería y señal Wi-Fi, historial, dashboard, reglas de alerta, alertas automáticas, reportes CSV/PDF, auditoría y control de acceso por rol. Toda la interfaz y validaciones deben estar en español.

El dispositivo debe poder enviar lecturas por HTTP, autenticarse con un token individual, actualizar su última conexión y disparar reglas de alerta configurables. El proyecto debe contener migraciones, modelos, relaciones, controladores, servicios, middleware, rutas web/API, vistas, seeders, datos de demostración, documentación y firmware de ejemplo.
