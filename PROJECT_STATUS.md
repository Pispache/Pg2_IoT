# Estado de la entrega

- Estructura preparada para Laravel 13.x.
- Código PHP validado con `php -l`.
- Interfaz sin dependencia de Node.js.
- La carpeta `vendor` no forma parte del ZIP; se genera con `composer install`.
- Las pruebas automatizadas incluidas se ejecutan con `php artisan test` después de instalar dependencias.
- El firmware requiere la librería DHT en Arduino IDE.
